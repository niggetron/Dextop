## Findings
- **P1 — Adaptive navigation absent.** No `calculateWindowSizeClass`, `currentWindowAdaptiveInfo`, `material3-adaptive`, or `NavigationRail/Drawer` anywhere in the app. Book is a fixed 60dp full-width taskbar (`BookUi.kt:1778`, `Dock()` 730-782) + one `BoxWithConstraints` launcher with magic caps 820/470dp (`BookUi.kt:864-917`). Settings uses fixed 340/320dp columns (`BookSettings.kt:167,416`) instead of list-detail. The 12.1" tablet is Large/Expanded class (1200–1600dp) — MD3 expects multi-pane + rail/drawer patterns; current shell ignores size class. Fix: add `material3-window-size-class` + `material3-adaptive`, hoist size class into state in `install()/place()`, drive launcher/panel widths, dock density, grid cells and a `NavigableListDetailPaneScaffold`.
- **P1 — Compose accessibility gap.** Icon-only controls have no semantics: `Sym` (`BookKit.kt:63-79`), `BookIconButton` (163-182), `DockItem` (`BookUi.kt:808-842`), `LauncherButton` (784-806), `AppCell` (937-956). Canvas-drawn glyphs (material paths) are invisible to TalkBack; menu rows/icon buttons are 44dp (`BookUi.kt:525,792,822`), below the 48dp target. Fix: `semantics/contentDescription`, `clearAndSetSemantics` on decorative icons, 48dp targets, traversal groups on overlay layers.
- **P2 — Theme under-configured.** `BookUi.kt:423` applies `MaterialExpressiveTheme(colorScheme, motionScheme)` only; no `typography`/`shapes` tokens and no contrast level. `BookTheme.scheme()` (`Book.kt:70-73`) uses dynamic color on S+ but has no 3-level contrast support. Fix: pass `typography`/`shapes` tokens and a `contrastLevel` derived from settings; document fallback to baseline schemes.
- **P2 — Raw colors in Compose shell.** Over-wallpaper/status bar `Color.White`, `Color(0x80000000)`, `Color(0xE6101418)` (`BookUi.kt:632-633,642,657,666,684,689,693`), drag target `Color.White.copy(...)` (1392-1393), `WallpaperText` shadow (`BookKit.kt:302-303`), wallpaper gradient + `positive` (`Book.kt:91,113-114`). `colors.xml:3-4` has 2 raw hex. Anti-pattern per SKILL §503-517. Fix: route through named exception tokens (`BookTokens.onWallpaper`, `wallpaperScrim`) or generate from scheme.
- **P2 — Shape tokens missing.** Expressive shape morph is used well (`MaterialShapes.Cookie9Sided.toShape()`, `BookUi.kt:787`), but corners are magic numbers (16/18/20/24/28dp across `BookUi.kt`, `BookKit.kt:204,228,240`, `BookPanels.kt:66`), never `MaterialTheme.shapes`. Fix: map to `extra-large 28 / large 16 / medium 12 / full`.
- **P2 — Motion partially expressive.** `MotionScheme.expressive()` + `defaultSpatialSpec/fastSpatialSpec` correctly used (`BookUi.kt:735,788,818,819,869`), but raw `spring(...)` in drag (1390,1396) and raw `fadeIn/fadeOut/AnimatedContent` (`BookUi.kt:606-607`, `BookPanels.kt:11-15,61-69`) bypass the motion scheme; no reduced-motion path. Fix: use scheme specs/emphasized easing (500/400/200ms) and an animator-duration-scale gate.
- **P2 — Edge-to-edge/IME.** System bars are hidden shell-wide (`PlasmaDesktopActivity.kt:46-47`, `MainActivity.kt:191-194`); `enableEdgeToEdge()` only in cardex (`CarDexActivity.kt:220`). No `imePadding()` on launcher/settings search fields (`BookUi.kt:880-895`, `BookSettings.kt:75`) and top inset is hardcoded `TOP_BAR=36dp` (`BookUi.kt:1777`) rather than `WindowInsets.safeDrawing/displayCutout`. Fix: inset-aware paddings for popup/panel/IME.
- **P3 — Elevation.** `tonalElevation=2dp` on panels (`BookPanels.kt:68`) is correct; elsewhere `shadowElevation=0` + `outlineVariant` dividers are correct. Minor: retain tonal elevation rather than adding shadows.

## Deliverable — design-system improvement plan (12.1" 120 Hz tablet)

1. **Tokens** — new `BookTokens.kt`: `MdSpacing` (4/8/16/24/32/48, I/O 2026 8dp rhythm), `BookShapes` (MD3 corner tokens), `BookTypography` (Roboto family, MD3 scale). Wire into `MaterialExpressiveTheme` at `BookUi.kt:423`; add `contrastLevel` from settings (standard/medium/high). Convert raw wallpaper colors to documented exception tokens; map `colors.xml` entries to roles or delete. Keep `Cookie9Sided` morph as the single expressive signature.
2. **Adaptive navigation** — add `material3-window-size-class` + `material3-adaptive`; classify width once and branch: launcher/panel max 840–1040dp (Large), 12-col grid density for 96dp cells, dock 60→80dp at Expanded, `NavigableListDetailPaneScaffold` for Settings. Preserve desktop taskbar metaphor; add rail/drawer only for future Book "workspace" views. Foldable APIs not needed (tablet, not foldable).
3. **Edge-to-edge** — keep full-ownership shell; replace `TOP_BAR`/`PANEL_SHADOW` math with `WindowInsets.safeDrawing + displayCutoutPadding()` and apply `.imePadding()` to all text fields and panel popups. `enableEdgeToEdge()` stays cardex-only.
4. **Expressive motion** — retain `MotionScheme.expressive()`; replace raw springs/fades with `MaterialTheme.motionScheme.*Spec()` and Emphasized easing; add reduced-motion gate via `ANIMATOR_DURATION_SCALE`; validate 120 Hz spring smoothness (no fixed 16ms assumptions).
5. **Accessibility** — 48dp targets everywhere; `contentDescription` on all icon controls; TalkBack traversal order for overlay/menu layers; 4.5:1 text contrast on wallpaper scrims; 3:1 on borders; verify tonal pairings (`onX` on `X`).
6. **MD3 compliance audit script outline** — `scripts/md3_audit.sh` (CI-friendly):
   - Inputs: `android/**/*.kt`, `*.xml`; optional file list.
   - Per-category checks (0–10, pass≥7/warn 4-6/fail≤3 per SKILL): color (`grep -rn 'Color(0x\|Color.White\|#[0-9a-fA-F]\{3,8\}'`, whitelist tokens), typography (`fontSize/fontWeight` without `MaterialTheme.typography`), shape (`RoundedCornerShape(<num>.dp)` magic numbers), elevation (tonalElevation vs shadow), components (M3 composables used), layout (window-size-class present, max-width), navigation (adaptive nav APIs), motion (`MotionScheme` usage), accessibility (semantics/contentDescription counts, 44dp targets), theming (`MaterialTheme` + dynamic + contrast).
   - Output SKILL.md §MD3 audit table + score/100 + critical file:line list; nonzero exit when critical count > 0 or score < 70.
   - Extend SKILL quick checks (SKILL.md:639-645) with Compose regexes; run in GitHub Actions (no local build).
