# W1A (M0, BUG-01) — Wave 1 Report

## Scope inspected

- All `beginSession/finishSession` (OperationLog only), `restoreSystemSettings`, `restoreSystemKeys`, `rememberGlobal/System`, `preparing/running/paused`, `snapshot`, `clear` callers.
- Existing persistence: SharedPreferences + `JSONObject` string blob (`SamsungDesktopSettings`, `ResolutionRepository`, `DisplayTopologyController`); `org.json:json:20240303` is already on the **test** classpath (app/build.gradle.kts:233). No fsync/WAL utility exists.

## Findings
- **P0 — BUG-01 confirmed.** `SessionJournal.restoreSystemSettings()` (SessionJournal.kt:104-134) hardcodes only 3 global keys. `AndroidDesktopOverrides.modernKeys` (DesktopEnvironment.kt:145-153) has 7; SDK-36 `aospFreeform()` (DesktopEnvironment.kt:244-252) mutates all 7 (5 as `null` = deletions). Leaked on every teardown/crash: `override_desktop_experience_features`, `override_desktop_mode_features`, `enable_non_resizable_multi_window`, `force_desktop_mode_on_secondary_displays`. On HyperOS 3 / API 36 these survive restart and alter desktop policy for all users.
- **P0 — no durable "before" for dynamic metrics.** `wm size`/`wm density` via hidden `IWindowManager.setForcedDisplaySize/setForcedDisplayDensityForUser` (MirrorService.kt:12343-12349,12677-12696,12900+) and `DisplayTopologyController.setDensity` (line 406) are never journaled. A crash leaves forced metrics pinned to the Dextop size/dpi.
- **P0 — no atomicity/fsync.** `running()` and `clear()` use `apply()` (no durability); each `rememberX()` is a separate `commit()` with no schema version, no checksum, no torn-write detection, no "all before-values durably recorded" barrier. `SavedGlobal` (DesktopModeConfigurator.kt:19-20) is a dead in-memory duplicate — it is only counted at restore (line 129), never used to restore.
- **P1 — inconsistent write channel.** Globals are written via app `Settings.Global.putString` (line 117), forced globals via privileged `cmd settings put` (configurator lines 55-62). App writes can be rejected/cached on HyperOS; restoration must use the privileged shell for all keys, with an app-context fallback.
- **P1 — double restore.** MirrorService.kt:14004-14005 calls `desktopModeConfigurator.restore()` (which itself calls `journal.restoreSystemSettings()`) *and* `sessionJournal.restoreSystemSettings()`.
- **P2 — rotation/overlay/wallpaper snapshots live in unrelated keys** (`rememberPhoneRotation`, `overlay_was_null`, `wallpaper_*_before`) and are not generalized; recovery snapshot (line 174) cannot enumerate what was changed.

## Deliverable

### Design
Single append-only NDJSON WAL at `context.filesDir/dextop_session/session_journal.wal`. Each line is `{"seq":N,"op":..,"ts":..,"raw":"<canonical JSON>","crc":<CRC32 of raw>}`. `raw` is canonical (recursively sorted keys) so CRC is deterministic on Android and JVM. Every mutation record is **fsync'd before** the corresponding `Settings`/`wm` write (`FileOutputStream.fd.sync()` + fsync of parent dir via `FileInputStream(dir).fd.sync()`). Ops: `begin` (fresh session id + overlay/wallpaper before-values), `phase`, `mutate`, `commit`. Replay: CRC-verify + strict `seq == prev+1`; a torn tail or gap is discarded. Restore replays mutations in reverse order, verifies, and only then writes `commit`; on any failure the journal stays open and is retried next launch. `beginSession` is idempotent (no-op unless phase `idle`), so the 3 existing `preparing()` call sites need no guarding.

Record ids: `global:<key>`, `system:<key>`, `secure:<key>`, `wm:size:<displayId>`, `wm:density:<displayId>`, `overlay`, `wallpaper`, `rotation`. Null-deletions are stored as `present=false`, `value=null` → restore issues `settings delete`.

```kotlin
package moe.n4tsu.dextop

import android.content.Context
import android.hardware.display.DisplayManager
import android.provider.Settings
import android.view.Display
import android.app.WallpaperManager
import org.json.JSONArray
import org.json.JSONObject
import java.io.File
import java.io.FileInputStream
import java.io.FileOutputStream
import java.util.UUID
import java.util.zip.CRC32

internal enum class JournalScope(val shellName: String) { GLOBAL("global"), SYSTEM("system"), SECURE("secure") }
internal data class JournalBefore(val present: Boolean, val value: String?)

/** Append-only, CRC-checked, fsync-before-write session journal. */
internal class AtomicSessionJournal(
    private val context: Context,
    private val walDir: File = File(context.filesDir, "dextop_session"),
    private val clock: () -> Long = { System.currentTimeMillis() }
) {
    private val walFile = File(walDir, "session_journal.wal")
    private val privileged = PrivilegedAccess("DextopSessionRecovery")
    private var state = blankState()
    private var seq = 0L

    init { walDir.mkdirs(); recover() }

    // ---------- public API ----------

    fun beginSession(width: Int, height: Int, density: Int, decorations: Boolean) {
        if (state.optString("phase", "idle") != "idle") return // retry/cover/Auto calls are idempotent
        val overlay = Settings.Global.getString(context.contentResolver, DisplayMirrorBackend.DISPLAY_SPECIFICATION)
        val wallpaper = WallpaperManager.getInstance(context)
        val mode = context.getSystemService(DisplayManager::class.java)
            .getDisplay(Display.DEFAULT_DISPLAY)?.mode
        val w = wallpaper.desiredMinimumWidth.takeIf { it > 0 } ?: mode?.physicalWidth
            ?: context.resources.displayMetrics.widthPixels
        val h = wallpaper.desiredMinimumHeight.takeIf { it > 0 } ?: mode?.physicalHeight
            ?: context.resources.displayMetrics.heightPixels
        val initial = JSONArray()
            .put(JSONObject().put("id", "overlay").put("kind", "overlay")
                .put("present", overlay != null).put("value", overlay ?: JSONObject.NULL))
            .put(JSONObject().put("id", "wallpaper").put("kind", "wallpaper")
                .put("width", w).put("height", h))
        append("begin", JSONObject()
            .put("sessionId", UUID.randomUUID().toString())
            .put("width", width).put("height", height).put("density", density)
            .put("decorations", decorations)
            .put("mutations", initial), reset = true)
    }

    /** MUST be called BEFORE each Settings write. First writer wins. */
    fun recordSetting(scope: JournalScope, key: String, before: JournalBefore, after: String?) {
        requireOpen()
        val id = "${scope.shellName}:$key"
        if (has(id)) return
        append("mutate", JSONObject()
            .put("id", id).put("kind", "setting")
            .put("namespace", scope.shellName).put("key", key)
            .put("present", before.present)
            .put("value", if (before.present && before.value != null) before.value else JSONObject.NULL)
            .put("after", after ?: JSONObject.NULL))
    }

    /** MUST be called BEFORE setForcedDisplaySize / setForcedDisplayDensityForUser. */
    fun recordWm(displayId: Int, command: String, before: String, after: String) {
        requireOpen()
        val id = "wm:$command:$displayId"
        if (has(id)) return
        append("mutate", JSONObject().put("id", id).put("kind", "wm")
            .put("displayId", displayId).put("command", command)
            .put("value", before).put("after", after))
    }

    fun recordRotation(frozen: Boolean, rotation: Int) {
        requireOpen()
        if (has("rotation")) return
        append("mutate", JSONObject().put("id", "rotation").put("kind", "rotation")
            .put("frozen", frozen).put("rotation", rotation))
    }

    fun running(displayId: Int) = append("phase", JSONObject().put("phase", "running").put("displayId", displayId))
    fun paused() = append("phase", JSONObject().put("phase", "paused").put("displayId", -1))

    fun phoneRotationState(): PhoneRotationState? {
        val m = find("rotation") ?: return null
        return PhoneRotationState(m.optBoolean("frozen"), m.optInt("rotation"))
    }

    /** Restores EVERY recorded mutation; returns false (and keeps the journal open) on any failure. */
    fun restoreAll(onRestoreExtras: () -> Boolean = { true }): Boolean {
        if (state.optString("phase", "idle") == "idle") { onRestoreExtras(); return true }
        append("phase", JSONObject().put("phase", "restoring").put("displayId", state.optInt("displayId", -1)))
        val records = mutations()
        var ok = true
        for (i in records.length() - 1 downTo 0) {
            val m = records.getJSONObject(i)
            if (m.optString("kind") == "rotation") continue
            ok = restoreOne(m) && ok
        }
        ok = onRestoreExtras() && ok
        if (!ok) {
            OperationLog.w(context, "SessionJournal", "restore incomplete; journal kept for retry, pending=${records.length()}")
            return false
        }
        append("commit", JSONObject().put("restoredAtMs", clock()))
        return true
    }

    fun restoreWallpaperDimensions(): Boolean {
        val m = find("wallpaper") ?: return true
        return runCatching {
            WallpaperManager.getInstance(context).suggestDesiredDimensions(m.getInt("width"), m.getInt("height"))
            true
        }.getOrDefault(false)
    }

    fun snapshot(): Map<String, Any> = mapOf(
        "recoverable" to (state.optString("phase", "idle") != "idle"),
        "transactionOpen" to (state.optString("phase", "idle") != "idle"),
        "phase" to state.optString("phase", "idle"),
        "width" to state.optInt("width"), "height" to state.optInt("height"),
        "density" to state.optInt("density"), "decorations" to state.optBoolean("decorations"),
        "updatedAt" to state.optLong("updatedAtMs"),
        "sessionId" to state.optString("sessionId"),
        "mutationCount" to mutations().length(),
        "version" to 1
    )

    fun clear() { synchronized(this) { writeTerminal() } }

    // ---------- compatibility delegates (remove after call sites migrate) ----------
    @Deprecated("beginSession") fun preparing(w: Int, h: Int, d: Int, dec: Boolean) = beginSession(w, h, d, dec)
    @Deprecated("recordSetting") fun rememberGlobal(k: String, v: String?) =
        recordSetting(JournalScope.GLOBAL, k, JournalBefore(v != null, v), null)
    @Deprecated("recordSetting") fun rememberSystem(k: String, v: String?) =
        recordSetting(JournalScope.SYSTEM, k, JournalBefore(v != null, v), null)
    @Deprecated("restoreAll") fun restoreSystemSettings() = restoreAll()
    @Deprecated("covered by restoreAll") fun restoreSystemKeys(keys: Collection<String>) = Unit

    // ---------- WAL internals ----------

    private fun requireOpen() = check(state.optString("phase", "idle") != "idle") {
        "Dextop session journal is idle; call beginSession first"
    }
    private fun blankState(): JSONObject = JSONObject()
        .put("version", 1).put("phase", "idle").put("mutations", JSONArray())
    private fun mutations(): JSONArray = state.optJSONArray("mutations") ?: JSONArray()
    private fun has(id: String) = (0 until mutations().length()).any { mutations().getJSONObject(it).optString("id") == id }
    private fun find(id: String): JSONObject? =
        (0 until mutations().length()).map { mutations().getJSONObject(it) }.firstOrNull { it.optString("id") == id }

    private fun append(op: String, data: JSONObject, reset: Boolean = false) {
        val raw = SessionWalCodec.canonical(data)
        val rec = JSONObject().put("seq", ++seq).put("op", op)
            .put("ts", clock()).put("raw", raw)
            .put("crc", SessionWalCodec.crc32(raw))
        val line = (rec.toString() + "\n").toByteArray(Charsets.UTF_8)
        synchronized(this) {
            FileOutputStream(walFile, !reset).use { out ->
                out.write(line)
                out.fd.sync()               // durability barrier BEFORE the platform mutation
            }
            runCatching { FileInputStream(walDir).use { it.fd.sync() } }
            applyEvent(rec, data)
        }
    }

    private fun applyEvent(rec: JSONObject, data: JSONObject) {
        val ts = rec.optLong("ts", clock())
        when (rec.optString("op")) {
            "begin" -> {
                state = blankState()
                data.keys().forEach { key -> if (key != "mutations") state.put(key, data.get(key)) }
                state.put("mutations", data.getJSONArray("mutations"))
            }
            "phase" -> { state.put("phase", data.getString("phase")); state.put("displayId", data.optInt("displayId", -1)) }
            "mutate" -> mutations().put(data)
            "commit" -> state = blankState()
            else -> Unit // forward compatible: unknown ops ignored
        }
        state.put("updatedAtMs", ts)
    }

    private fun recover() {
        state = blankState(); seq = 0
        if (!walFile.exists()) return
        walFile.forEachLine { line ->
            val rec = runCatching { JSONObject(line) }.getOrNull() ?: return@forEachLine
            val raw = rec.optString("raw")
            if (raw.isBlank() || SessionWalCodec.crc32(raw) != rec.optLong("crc", -1)) return@forEachLine
            val s = rec.optLong("seq", -1)
            if (s != seq + 1) return@forEachLine
            seq = s
            runCatching { applyEvent(rec, JSONObject(raw)) }
        }
    }

    private fun writeTerminal() {
        seq++
        val raw = SessionWalCodec.canonical(JSONObject().put("phase", "idle"))
        val rec = JSONObject().put("seq", seq).put("op", "commit").put("ts", clock())
            .put("raw", raw).put("crc", SessionWalCodec.crc32(raw))
        FileOutputStream(walFile, false).use { out ->
            out.write((rec.toString() + "\n").toByteArray(Charsets.UTF_8)); out.fd.sync()
        }
        runCatching { FileInputStream(walDir).use { it.fd.sync() } }
        state = blankState()
    }

    private fun restoreOne(m: JSONObject): Boolean {
        return when (m.optString("kind")) {
            "setting" -> {
                val scope = JournalScope.valueOf(m.getString("namespace").uppercase())
                val before = if (m.isNull("value")) null else m.getString("value")
                val written = writeSetting(scope, m.getString("key"), before)
                val verified = readSetting(scope, m.getString("key")) == before
                written && verified
            }
            "wm" -> {
                val value = m.getString("value") // "reset" | "WxH" | "dpi"
                privileged.execute("wm", m.getString("command"), value, "-d", m.getInt("displayId").toString()).succeeded
            }
            "overlay" -> {
                val before = if (m.isNull("value")) null else m.getString("value")
                Settings.Global.putString(context.contentResolver, DisplayMirrorBackend.DISPLAY_SPECIFICATION, before)
                    .also { if (it) state.put("overlayRestored", true) }
            }
            "wallpaper" -> true // handled by restoreWallpaperDimensions()
            else -> true
        }
    }

    private fun writeSetting(scope: JournalScope, key: String, value: String?): Boolean {
        if (privileged.isAvailable()) {
            val r = if (value == null)
                privileged.execute("settings", "delete", scope.shellName, key)
            else privileged.execute("settings", "put", scope.shellName, key, value)
            if (r.succeeded) return true
        }
        return runCatching {
            when (scope) {
                JournalScope.GLOBAL -> Settings.Global.putString(context.contentResolver, key, value)
                JournalScope.SYSTEM -> Settings.System.putString(context.contentResolver, key, value)
                JournalScope.SECURE -> false
            }
        }.getOrDefault(false)
    }

    private fun readSetting(scope: JournalScope, key: String): String? {
        val viaShell = if (privileged.isAvailable())
            privileged.execute("settings", "get", scope.shellName, key)
                .takeIf { it.succeeded }?.output?.trim()?.takeUnless { it.isBlank() || it == "null" }
        else null
        return viaShell ?: runCatching {
            when (scope) {
                JournalScope.GLOBAL -> Settings.Global.getString(context.contentResolver, key)
                JournalScope.SYSTEM -> Settings.System.getString(context.contentResolver, key)
                JournalScope.SECURE -> null
            }
        }.getOrNull()
    }
}

/** Pure JVM-testable (org.json only) codec — put in its own file if preferred. */
internal object SessionWalCodec {
    fun crc32(raw: String): Long {
        val crc = CRC32(); crc.update(raw.toByteArray(Charsets.UTF_8)); return crc.value
    }
    fun canonical(value: Any): String = when (value) {
        is JSONObject -> value.keys().asSequence().sorted().joinToString(",", "{", "}") { k ->
            "\"$k\":${canonical(value.get(k))}"
        }
        is JSONArray -> (0 until value.length()).joinToString(",", "[", "]") { canonical(value.get(it)) }
        is String -> JSONObject.quote(value)
        JSONObject.NULL -> "null"
        is Number, is Boolean -> value.toString()
        else -> JSONObject.quote(value.toString())
    }
}
```

## Risks / device testing needed

Verify with an instrumented power-cut test: kill process mid-`preparing`, mid-`wm density`, and mid-restore, then relaunch and assert `Settings.Global`/`wm size/density` return to pre-session values.
