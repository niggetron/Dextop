## Findings
- **P0 — version source is Flutter.** `app/build.gradle.kts:61-62,78-79` uses `flutter.compileSdkVersion/ndkVersion/targetSdkVersion/versionCode/versionName`; `release-apk.yml:105`, `manual-release.yml:64`, `build_release_apk.sh:9`, `build_play_aab.sh:11` `awk` pubspec; `release-please/config.json:3` is `"release-type": "dart"`; `release.yml:83-96` rewrites pubspec. Deleting `pubspec.yaml` first breaks every release path. Fix: keep a **version-only `pubspec.yaml`** (`version:` + `name:` only) as the manual anchor, parse it in Gradle with a regex, and drop only `flutter { }`/plugin; later migrate to `android/version.properties` + release-please `extra-files` in a separate PR.
- **P0 — settings store is Flutter's file.** `FlutterSharedPreferences.xml` with `flutter.`-prefixed keys is the live native store (e.g. `MirrorService.kt:9698`, `CardexRelayService.kt:569`). Deleting Flutter without a compat wrapper loses all user settings on device. Fix: introduce `DextopPrefs` that keeps the file name/prefix, migrate call sites while Flutter still ships; one-shot rename only after a release cycle.
- **P0 — build-output path is Flutter-specific.** `build/app/outputs/flutter-apk/…` hardcoded in `release-apk.yml:126,147,151-154`, `debug-apk.yml:74,83`, `build_release_apk.sh:11-13`. Native path is `build/app/outputs/apk/github/debug/app-github-debug.apk`.
- **P0 — l10n generators read `lib/l10n`.** `generateNativeStrings` (`app/build.gradle.kts:169-190`) and `generateUiStrings` (`android/build.gradle.kts:25-50`) are `preBuild` dependencies for **app and cardex**. Deleting `lib/` before relocating catalogs breaks all modules' builds and `check_localization.py:38-56`.
- **P1 — three Kotlin files import `io.flutter.*`** (`MainActivity`, `DextopShortcuts:17,99,187-190`, `LinuxChannel:5-6,17-28`): must be rewritten before removing the plugin, else Kotlin compile fails.
- **P1 — `settings.gradle.kts:2-11,21` requires `local.properties` + `flutter.sdk` + Flutter plugin loader.** Any Gradle invocation fails if the plugin is removed last without cleaning this.
- **P1 — `gradle.properties:3-6`** carries Flutter migrator flags (`builtInKotlin=false`, `newDsl=false`); removal changes Kotlin DSL behavior — verify in CI.
- **P2 — manifest Flutter residue**: `io.flutter.embedding.android.NormalTheme` (`:117-120,132-134`), `flutterEmbedding=2` (`:266-270`), PROCESS_TEXT queries used only by `ProcessTextPlugin` (`:372-382`), `LaunchTheme`/`NormalTheme` styles. `application.name=DextopApplication` (`:45`) and `DextopLauncherActivity` (`:136-149`) have **no** Flutter dependency — leave intact.
- **P2 — Firebase/Analytics**: `firebase_core`/`firebase_analytics` are Dart-only; `google-services.json` plugin (`app/build.gradle.kts:11-13`) also serves native Cast — keep it; decide replacement native analytics explicitly, don't delete by association.
- **P3 — `dev.flutter.flutter-gradle-plugin` injects the `profile` build type**; `src/profile/AndroidManifest.xml` becomes dead. `GeneratedPluginRegistrant.java` is gitignored and unreferenced by Kotlin — safe.
