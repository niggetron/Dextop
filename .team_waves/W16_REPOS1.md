- **https://github.com/jqssun/android-display-mirror** — Trusted virtual-display flags matrix (`VIRTUAL_DISPLAY_FLAG_TRUSTED`, `OWN_DISPLAY_GROUP`, `ALWAYS_UNLOCKED`, `TOUCH_FEEDBACK_DISABLED` API 33; `DEVICE_DISPLAY_GROUP` 34), input injection/source mapping, DisplayListener hotplug. - **https://github.com/farmerbb/SecondScreen** — Long-standing `IWindowManager` resolution/DPI/rotation profile implementation (credited by Extend). Concrete pattern for `DesktopModeConfigurator.configureDisplay()` session-scoped IO + cancel (BUG-02), M4 backend A.

### B. SurfaceControl / AHardwareBuffer zero-copy
- **https://github.com/GlassOnTin/wayland-android** (`buffer_presenter.c/.h`) — Minimal, copy-pasteable `ASurfaceControl_createFromWindow` → `ASurfaceTransaction_setBuffer(ahb, -1)` → apply, with runtime API<29 guard and `ANDROID_UNAVAILABLE_SYMBOLS_ARE_WEAK`. Ideal clean replacement model for `deck_ahb_broker.inc` (BUG-05): no stack buffer, no per-alloc dlopen/dlsym/dlclose. Maps to M6 Rust graphics + `dextop-wayland-ahb-zero-copy` skill. Cite: https://raw.githubusercontent.com/GlassOnTin/wayland-android/main/buffer_presenter.c
- **https://github.com/Xtr126/wlroots-android-bridge** + **https://github.com/Xtr126/labwc-android** — Full production zero-copy: minigbm/gbm gralloc handle → import AHardwareBuffer into wlroots via `cros_gralloc_handle.h`, each window presented with `ASurfaceTransaction_setBuffer`; uses APIs 29/33/34/36; GPU-resident path, hardware overlays/direct scanout. Canonical for M6 Rust Wayland/graphics and BUG-05 correct fence/ownership/lifetime handling.
- **https://github.com/GlassHaven/wayland-android** — arm64-v8a cross-compilation of labwc + 20 deps, with `ahb_allocator.c`, `buffer_presenter.c`, `jni_bridge.c`, build scripts and sysroot headers. Maps to M6 and the C-only boundary retention (PRoot/fastpath/preload) in BRIEF.
- **https://github.com/qsh3525/WayLand** — dmabuf fd → `VK_ANDROID_external_memory_android_hardware_buffer` → SurfaceControl `USAGE_COMPOSITOR_OVERLAY` → HWC scanout; enforces `WAYLANDIE_FINAL_COPY=forbidden` so no silent CPU blit. Strong pattern for BUG-05 (enforce zero-copy, no weak fallback) and M6 graphics.
- **https://github.com/kiryldz/android-hardware-buffer-camera** + **https://docs.vulkan.org/samples/latest/samples/extensions/open_cl_interop_arm/README.html** — AHB allocation/import/export across Vulkan/GLES and fence sync; minSdk 26, NDK 25. Maps to M5 Rust crates (AHardwareBuffer wrapper) and M6.
- **https://android.googlesource.com/platform/frameworks/native/+/refs/heads/main/include/android/surface_control.h** — API 36 `ASurfaceTransaction_setBufferWithRelease(buffer, acquire_fd, context, callback)` — the stable public replacement for manual release fences; requires `AHARDWAREBUFFER_USAGE_GPU_SAMPLED_IMAGE`. Directly fixes BUG-05 buffer-reuse lifetime; prefer over hidden APIs per BRIEF.
- **https://github.com/adiimanav/moreland** — Rust `crates/` + Android app, DMA-BUF capture → in-GPU encode, zero-copy with explicit multi-GPU caveat. Useful reference for M5 Rust crates and zero-copy correctness documentation (M8).

## Risks / device testing needed
- `HyperDesktopUnlock` targets HyperOS **4 / Android 17**, not HyperOS 3 / Android 16 — treat hooks as hypotheses; verify on Redmi Pad Pro 5G before adopting (M4-E).
- `SurfaceControl.createDisplay` is removed/broken on Android 15+ — confirm the `DisplayManager.createVirtualDisplay` fallback works on API 36; probe in M1.
- Hidden APIs (`setDisplayId`, `IDisplayManager` create/release, `IWindowManager` forced size) need versioned adapters + HiddenApiBypass verification (BRIEF constraint); prefer public ASurfaceControl/AHB paths (API 36 `setBufferWithRelease`).
- Zero-copy repos assume gralloc/minigbm access and GPU-overlay support; vendor drivers on MediaTek/Dimensity may differ — validate HWC overlay/direct scanout on-device (BUG-05, M6).
- 120 Hz virtual-display refresh rate must divide leader VSYNC (AOSP VirtualDisplayAdapter) — verify 60/120 fps selection on-device (M4).
