# W2A (M0, BUG-04) — Wave 2 Report

## Scope inspected
- `android/app/src/main/cpp/wayland/deck_direct.inc` (all 175 lines; full ownership/lifetime chain).
- Callers: `compositor.c` — `direct_frames` list (251), `deck_direct_present()` call (686), `deck_direct_hide(false/true)` (718, 801, 1711, 2913, 2930), `gpu_job_*` fd callback pattern (440-475, 745-746), teardown drain (3104-3105, 3154), other `wl_event_loop_add_fd` sites (1599, 3184, 3218).
- `gpu_present.c` (341-349: `deck_output_init()` eligibility; 412-506: Vulkan fence separate from AHB fence — not implicated).
- `gpu_buffer_hold/unref` (`compositor.c:423-438`), `deck_buffer_release_queue/cancel` (`deck_buffer_release.inc`), `deck_ahb_broker.inc:67-68` (correct `EINTR` precedent).
- wl_event_loop fd sources are **level-triggered** (`EPOLLIN|EPOLLHUP|EPOLLERR`, no `EPOLLET`); source callbacks' return value is ignored by `wl_event_loop_dispatch()`. Removing the source is the only way to stop re-dispatch. Removing a source from inside its own callback is supported by libwayland (already done at line 51).

## Findings

- **P0 — `deck_direct.inc:45` busy-spin.** `if (recvmsg(...) != 1) return 0;` leaves the source registered on EOF (`n==0`, peer closed `sockets[1]` on hide/teardown/transaction failure) or on any fatal error (`n==-1`, e.g. `ECONNRESET`, `EBADF`). Level-triggered epoll immediately reports the fd readable again → 100% core on the compositor thread, thermal throttling and dropped frames on Redmi Pad Pro / HyperOS 3. Also ignores `MSG_CTRUNC`, so truncated ancillary data is treated as success. Fix: retry only `EINTR`/`EAGAIN` (with no HUP/ERROR bit); on EOF/fatal/truncation call `deck_direct_frame_destroy()` which removes the source.

- **P0 — `deck_direct.inc:55` missing NULL check leaks fence FD + AHB/dmabuf ref.** After `wl_event_source_remove(frame->source); close(frame->fd); frame->fd = fence; frame->socket = false;`, a NULL `wl_event_loop_add_fd()` leaves the frame in `comp->direct_frames` with **no source**, still owning (a) the received SCM_RIGHTS fence FD and (b) the `gpu_buffer_hold()`/`AHardwareBuffer_acquire()` ref taken for the frame. It is never released until process teardown → permanent dmabuf starvation (buffer stays `busy>0`, `deck_buffer_release_queue` never fires) and FD exhaustion across sessions. Secondary hazard: `frame->source` is not set to NULL at line 51, so any subsequent `deck_direct_frame_destroy()` (e.g. teardown at `compositor.c:3105`) calls `wl_event_source_remove()` on the already-freed source → UAF. Fix: set `frame->source = NULL` right after remove; destroy the frame if `wl_event_loop_add_fd()` returns NULL (destroy closes `frame->fd`=fence, unrefs dmabuf/AHB, unlinks the frame).

- **P1 — `deck_direct.inc:39` HUP/ERROR mask gap.** Guard `if (!(mask & WL_EVENT_READABLE)) return 0;` ignores `WL_EVENT_HANGUP|WL_EVENT_ERROR`. A HUP-only delivery returns without removing the source → same busy-spin. Fix: include all three bits; the socket branch's `recvmsg()` then returns 0/error and destroys, the fence branch destroys unconditionally.

- **P1 — `deck_direct.inc:75` `sendmsg()` result ignored.** On `EAGAIN` (nonblocking `SOCK_SEQPACKET`) the release byte+fence is dropped; `close(fence)` and `close(previous->fd)` still happen, so no FD leak, but the receiver now sees EOF and (with the P0 fix) destroys the frame *before the fence signals* → possible buffer reuse corruption. Cannot block (reader is the same event-loop thread). Keep as follow-up: retry bounded, or register a `WL_EVENT_WRITABLE` retry source carrying the fence; minimum now is to log `errno` so the drop is observable.

- **P2 — `compositor.c:745-746`** same unchecked `wl_event_loop_add_fd()` pattern for `gpu_job`: `job->source` stays NULL, fence FD and held buffers survive until `gpu_jobs_collect(drained)`/`gpu_job_finish()`. Not a permanent leak, but delay the same way as BUG-04; add explicit `else` cleanup (`close(job->fence); job->fence = -1;`) if hardening in the same wave.

- **P2 — `deck_direct.inc:150`** `ASurfaceTransaction_create()` return unchecked before `ASurfaceTransaction_setBuffer()`; OOM → NULL deref. Add `if (!tx) { AHardwareBuffer_release(submission->buffer); gpu_buffer_unref(b, true); ... goto fail/cleanup; }`.

## Deliverable

### Exact patch 1 — replace `deck_direct.inc` lines 37-59 (`deck_direct_released`)

```c
static int deck_direct_released(int fd, uint32_t mask, void *data) {
    struct deck_direct_frame *frame = data;
    const uint32_t events = WL_EVENT_READABLE | WL_EVENT_HANGUP | WL_EVENT_ERROR;
    if (!(mask & events)) return 0;
    if (frame->socket) {
        char byte, ancillary[CMSG_SPACE(sizeof(int))];
        struct iovec iov = {&byte, 1};
        struct msghdr msg = {.msg_iov = &iov, .msg_iovlen = 1,
            .msg_control = ancillary, .msg_controllen = sizeof(ancillary)};
        ssize_t n = recvmsg(fd, &msg, MSG_DONTWAIT | MSG_CMSG_CLOEXEC);
        if (n < 0 && errno == EINTR) return 0;
        if (n < 0 && (errno == EAGAIN || errno == EWOULDBLOCK) &&
            !(mask & (WL_EVENT_HANGUP | WL_EVENT_ERROR))) return 0; /* spurious wakeup */
        if (n != 1 || (msg.msg_flags & (MSG_CTRUNC | MSG_TRUNC))) {
            /* EOF, fatal error, or truncated SCM_RIGHTS: the fd stays level-triggered
             * readable forever unless the source is removed. Destroys source + fd +
             * held dmabuf/AHB ref and unlinks the frame. */
            deck_direct_frame_destroy(frame);
            return 0;
        }
        int fence = -1;
        for (struct cmsghdr *c = CMSG_FIRSTHDR(&msg); c; c = CMSG_NXTHDR(&msg, c))
            if (c->cmsg_level == SOL_SOCKET && c->cmsg_type == SCM_RIGHTS &&
                c->cmsg_len == CMSG_LEN(sizeof(int))) memcpy(&fence, CMSG_DATA(c), sizeof(fence));
        if (fence >= 0) {
            wl_event_source_remove(frame->source);
            frame->source = NULL;            /* prevents double-remove in destroy/teardown */
            close(frame->fd);                /* old socketpair read end */
            frame->fd = fence;               /* MSG_CMSG_CLOEXEC already set on receipt */
            frame->socket = false;
            frame->source = wl_event_loop_add_fd(frame->loop, fence,
                WL_EVENT_READABLE, deck_direct_released, frame);
            if (!frame->source) deck_direct_frame_destroy(frame); /* closes fence, unrefs AHB */
        } else deck_direct_frame_destroy(frame); /* no fence => release now */
    } else deck_direct_frame_destroy(frame);     /* sync_file signalled: release + remove source */
    return 0;
}
```

No signature/struct changes; `errno.h`, `string.h`, `_GNU_SOURCE` already available via `compositor.c:19-35`.

### Exact patch 2 — optional defensive hardening of `deck_direct_frame_destroy` (lines 29-35)

```c
static void deck_direct_frame_destroy(struct deck_direct_frame *frame) {
    if (frame->source) { wl_event_source_remove(frame->source); frame->source = NULL; }
    if (frame->fd >= 0) { close(frame->fd); frame->fd = -1; }
    gpu_buffer_unref(frame->buffer, true);
    wl_list_remove(&frame->link);
    free(frame);
}
```

(Required only if the double-destroy path can be reached by tests; patch 1 alone fixes the production double-remove.)

## Risks / device testing needed
- Level-triggered removal from inside a libwayland fd callback is assumed safe per existing code (line 51) and Weston precedent; verify with the harness + on-device stress (rapid hide/show, app kill during presentation) that no `wl_event_source_remove` UAF appears under ASan.
- Sync_file FDs signaled but never read: source removal must happen or epoll spins; harness mode 3 covers the HUP-only variant seen on some kernels.
- On device (Redmi Pad Pro 5G, API 36 / HyperOS 3): run 1000 present→release cycles via the DECK-direct path, confirm `/proc/<pid>/fd` stable, `dumpsys` GPU/dmabuf busy count stable, no frame drops from compositor-thread CPU, and that early-teardown release fences still arrive before buffer reuse.
- `MSG_CMSG_CLOEXEC` is Linux/Android-specific but already used in `deck_ahb_broker.inc`; no hidden API involved.
- `wl_event_loop_add_fd` NULL on Android is rare (epoll_ctl failure/EMFILE); the fix keeps the system fail-safe: drop the frame rather than leak the buffer.
- No builds run locally; GitHub Actions must compile both flavors and the new native job.
