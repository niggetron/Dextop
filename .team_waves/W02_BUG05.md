## Findings
- **P0 — forgeable auth + 64 KB stack** `deck_ahb_broker.inc:5-17`: any process able to set `DEXTOP_STEAM_INSIDE=1` gets gralloc fd transfers. Reads `/proc/<pid>/environ` into `char bytes[65536]` on stack. Same defect at `compositor.c:1738` (`char data[65536]`) and `deck_ahb_protocol.inc:12,53` (global is Steam-only). Fix: `SO_PEERCRED` uid==appUid + 256-bit per-session capability token in wire v2; delete environ read entirely.
- **P0 — per-allocation dlsym/dlclose** `deck_ahb_broker.inc:38-42`, `deck_ahb_protocol.inc:34-38`: `dlopen`/`dlsym`/`dlclose` on every AHB; `get_handle` storage survives `dlclose` (comment concedes this at protocol:37). Fix: resolve once at init, keep `libnativewindow.so` loaded for process lifetime.
- **P1 — blocking, thread-per-connection** `deck_ahb_broker.inc:19-26,62-82,89-95`: detached thread per client, blocking `recv`/`recvmsg` with 5 s `SO_RCVTIMEO`; handle transfer can stall; no epoll FD-guard on per-client sources (BUG-04 pattern). Fix: non-blocking event-loop state machine.
- **P2 — zero-copy gated to Steam** `compositor.c:1751-1752`, `deck_ahb_protocol.inc:12,53`, `deck_policy.h:5-8`: benchmark-only, not production. Fix: runtime toggle `dextop.compositor=rust|c` + `DEXTOP_AHB_ZEROCOPY`; advertise v4 globals to all clients when on.

### B. `deck_ahb_broker.inc` (full replacement)
```c
/* Android allocates gralloc buffers on behalf of the Deck glibc WSI.
 * All socket I/O is non-blocking on the compositor event loop. */
#include <dlfcn.h>
#include <sys/random.h>
#include <sys/system_properties.h>
#include "deck_ahb_wire.h"

static const void *(*g_ahb_get_handle)(const AHardwareBuffer *);
static uint8_t g_ahb_token[DECK_AHB_TOKEN_LEN];
static uid_t g_ahb_app_uid;            /* set once from Java getuid() */
static void *g_ahb_nw_handle;          /* intentionally never dlclose'd */

struct handle_header { int version, num_fds, num_ints, data[]; };

static int deck_ahb_cache_symbols(void) {
    g_ahb_nw_handle = dlopen("libnativewindow.so", RTLD_NOW | RTLD_LOCAL);
    if (!g_ahb_nw_handle) return -1;
    g_ahb_get_handle = (const void *(*)(const AHardwareBuffer *))
        dlsym(g_ahb_nw_handle, "AHardwareBuffer_getNativeHandle");
    return g_ahb_get_handle ? 0 : -1;   /* keep library resident */
}

static int deck_ahb_init(uid_t app_uid, const char *socket_name) {
    g_ahb_app_uid = app_uid;
    if (deck_ahb_cache_symbols()) return -1;
    if (getrandom(g_ahb_token, sizeof(g_ahb_token), 0) != (ssize_t)sizeof(g_ahb_token)) return -1;
    /* publish token 0600 next to the abstract socket name for the launcher */
    char path[108 + 16], hex[DECK_AHB_TOKEN_LEN * 2 + 1];
    static const char d[] = "0123456789abcdef";
    for (size_t i = 0; i < DECK_AHB_TOKEN_LEN; ++i) {
        hex[2*i] = d[g_ahb_token[i] >> 4]; hex[2*i+1] = d[g_ahb_token[i] & 15];
    }
    hex[sizeof(hex)-1] = 0;
    int n = snprintf(path, sizeof(path), "%s.ahb.token", socket_name);
    if (n < 0 || (size_t)n >= sizeof(path)) return -1;
    int fd = open(path, O_WRONLY | O_CREAT | O_TRUNC | O_CLOEXEC, 0600);
    if (fd < 0) return -1;
    fchmod(fd, 0600);
    ssize_t w = write(fd, hex, strlen(hex));
    close(fd);
    return w == (ssize_t)strlen(hex) ? 0 : -1;
}

static bool deck_ahb_peer_allowed(int fd, const uint8_t *token) {
    struct ucred peer; socklen_t len = sizeof(peer);
    if (getsockopt(fd, SOL_SOCKET, SO_PEERCRED, &peer, &len) || len != sizeof(peer) ||
        peer.uid != g_ahb_app_uid || !token) return false;
    uint8_t diff = 0;                         /* constant-time compare */
    for (size_t i = 0; i < DECK_AHB_TOKEN_LEN; ++i) diff |= token[i] ^ g_ahb_token[i];
    return diff == 0;
}

enum ahb_conn_state { AHB_REQ, AHB_CMD };
struct deck_ahb_conn {
    struct comp *comp;
    struct wl_event_source *source;
    int fd;
    uint8_t request[sizeof(struct deck_ahb_request)];
    size_t request_len;
    AHardwareBuffer *buffer;
    enum ahb_conn_state state;
};

static void deck_ahb_conn_destroy(struct deck_ahb_conn *c) {
    if (c->source) wl_event_source_remove(c->source);
    if (c->buffer) AHardwareBuffer_release(c->buffer);
    close(c->fd);
    free(c);                                  /* exactly one owner, all paths */
}

static int deck_ahb_send_reply(int fd, AHardwareBuffer *buffer,
                               const struct handle_header *h) {
    struct deck_ahb_reply reply = {0};
    AHardwareBuffer_describe(buffer, &reply.desc);
    reply.status = 0;
    reply.num_fds = h->num_fds;
    reply.num_ints = h->num_ints;
    memcpy(reply.ints, h->data + h->num_fds, h->num_ints * sizeof(int));
    char ancillary[CMSG_SPACE(DECK_AHB_MAX_FDS * sizeof(int))] = {0};
    struct iovec iov = {&reply, sizeof(reply)};
    struct msghdr msg = {.msg_iov = &iov, .msg_iovlen = 1, .msg_control = ancillary,
        .msg_controllen = CMSG_SPACE((size_t)h->num_fds * sizeof(int))};
    struct cmsghdr *c = CMSG_FIRSTHDR(&msg);
    c->cmsg_level = SOL_SOCKET; c->cmsg_type = SCM_RIGHTS;
    c->cmsg_len = CMSG_LEN((size_t)h->num_fds * sizeof(int));
    memcpy(CMSG_DATA(c), h->data, (size_t)h->num_fds * sizeof(int));
    return sendmsg(fd, &msg, MSG_DONTWAIT | MSG_NOSIGNAL) == sizeof(reply) ? 0 : -1;
}

static int deck_ahb_client_ready(int fd, uint32_t mask, void *data) {
    struct deck_ahb_conn *c = data;
    if (mask & (WL_EVENT_HANGUP | WL_EVENT_ERROR)) goto fail;
    if (!(mask & WL_EVENT_READABLE)) return 0;

    if (c->state == AHB_REQ) {
        ssize_t n = recv(fd, c->request + c->request_len,
                         sizeof(c->request) - c->request_len, MSG_DONTWAIT);
        if (n > 0) c->request_len += (size_t)n;
        else if (n == 0) goto fail;            /* EOF: destroy source, no spin */
        else if (errno == EINTR || errno == EAGAIN || errno == EWOULDBLOCK) return 0;
        else goto fail;
        if (c->request_len < sizeof(c->request)) return 0;

        const struct deck_ahb_request *req = (const void *)c->request;
        if (!deck_ahb_peer_allowed(fd, req->token) ||
            req->version != DECK_AHB_WIRE_VERSION || req->operation != 1 ||
            !req->desc.width || !req->desc.height ||
            req->desc.width > 16384 || req->desc.height > 16384 ||
            req->desc.layers != 1 || (req->desc.format != 1 && req->desc.format != 2) ||
            req->desc.rfu0 || req->desc.rfu1) goto fail;
        const uint64_t allowed =
            AHARDWAREBUFFER_USAGE_GPU_SAMPLED_IMAGE | AHARDWAREBUFFER_USAGE_GPU_COLOR_OUTPUT |
            AHARDWAREBUFFER_USAGE_COMPOSER_OVERLAY | AHARDWAREBUFFER_USAGE_CPU_READ_RARELY |
            (UINT64_C(1) << 28);
        if (req->desc.usage & ~allowed) goto fail;

        AHardwareBuffer *buffer = NULL;
        if (AHardwareBuffer_allocate(&req->desc, &buffer)) goto fail;
        const struct handle_header *h = g_ahb_get_handle ? g_ahb_get_handle(buffer) : NULL;
        if (!h || h->num_fds < 1 || h->num_fds > DECK_AHB_MAX_FDS ||
            h->num_ints < 0 || h->num_ints > DECK_AHB_MAX_INTS) {
            AHardwareBuffer_release(buffer); goto fail;
        }
        if (deck_ahb_send_reply(fd, buffer, h)) {
            AHardwareBuffer_release(buffer); goto fail;
        }
        c->buffer = buffer;
        c->state = AHB_CMD;
        return 0;
    }

    for (;;) {                                 /* handle-transfer commands */
        char byte, control[CMSG_SPACE(sizeof(int))] = {0};
        struct iovec in = {&byte, 1};
        struct msghdr cmd = {.msg_iov = &in, .msg_iovlen = 1,
            .msg_control = control, .msg_controllen = sizeof(control)};
        ssize_t n = recvmsg(fd, &cmd, MSG_DONTWAIT | MSG_CMSG_CLOEXEC);
        if (n < 0) {
            if (errno == EINTR) continue;
            if (errno == EAGAIN || errno == EWOULDBLOCK) return 0;
            goto fail;
        }
        if (n == 0) goto fail;                 /* EOF: remove source */
        int target = -1, extra = -1;
        for (struct cmsghdr *cm = CMSG_FIRSTHDR(&cmd); cm; cm = CMSG_NXTHDR(&cmd, cm)) {
            if (cm->cmsg_level != SOL_SOCKET || cm->cmsg_type != SCM_RIGHTS ||
                cm->cmsg_len != CMSG_LEN(sizeof(int))) continue;
            int v; memcpy(&v, CMSG_DATA(cm), sizeof(v));
            if (target < 0) target = v; else extra = v;
        }
        if (extra >= 0) close(extra);          /* no fd accumulation */
        int status = -1;
        if (target >= 0 && c->buffer) {
            struct timeval tv = {.tv_sec = 5};
            setsockopt(target, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof(tv));
            status = AHardwareBuffer_sendHandleToUnixSocket(c->buffer, target);
            close(target);
        } else if (target >= 0) close(target);
        if (send(fd, &status, sizeof(status), MSG_DONTWAIT | MSG_NOSIGNAL) != sizeof(status))
            goto fail;
    }
fail:
    deck_ahb_conn_destroy(c);
    return 0;
}

static int deck_ahb_accept(int fd, uint32_t mask, void *data) {
    struct comp *comp = data;                  /* caller now passes comp */
    if (mask & (WL_EVENT_HANGUP | WL_EVENT_ERROR)) return 0;
    for (;;) {
        int client = accept4(fd, NULL, NULL, SOCK_CLOEXEC | SOCK_NONBLOCK);
        if (client < 0) {
            if (errno == EINTR) continue;
            break;                             /* EAGAIN: event loop driven */
        }
        struct deck_ahb_conn *c = calloc(1, sizeof(*c));
        if (!c) { close(client); continue; }
        c->comp = comp; c->fd = client; c->state = AHB_REQ;
        c->source = wl_event_loop_add_fd(comp->loop, client,
                                         WL_EVENT_READABLE, deck_ahb_client_ready, c);
        if (!c->source) { close(client); free(c); } /* BUG-04 FD-leak guard */
    }
    return 0;
}
```

```c
    if (global == comp->normal_dmabuf_global) return !deck;
    return true;
}
```

## CI verification notes (GitHub Actions only, no local builds)
1. **No local compile.** Add `tool/tests` jobs to the existing GHA Linux runner; patch probes to v2 token.
2. **Static guard:** compile probe with `-Wstack-usage=4096 -Werror` → fails if any 64 KB frame returns. `grep -R "65536\|/proc/%d/environ\|dlclose" deck_ahb_*` must be empty in cpp/wayland.
3. **dlsym-count test:** `LD_PRELOAD` shim counting `dlsym("AHardwareBuffer_getNativeHandle")`; 100 allocations → count == 1.
4. **Auth negative tests:** (a) connect with wrong token → `reply.status != 0`, no `SCM_RIGHTS` fd; (b) spoof `DEXTOP_STEAM_INSIDE=1` without token → rejected; (c) different-uid child → `SO_PEERCRED` rejection. Existing `deck_controller_read_access.py` extends with token-strip case; `linux_deck_runtime_probe.c` adds token path.
5. **FD-leak soak:** 1000 sequential alloc → send handle → release; assert `/proc/self/fd` count flat and no leaked wl_event_source (BUG-04 regression shield).
6. **Non-blocking/spin test:** kill client mid-transfer; `clock_gettime` CPU over 5 s must stay <1 % — `recvmsg()==0` removes source.
7. **Toggle test:** `WaylandPresentationProbe.java --dmabuf-feedback` with `dextop.compositor=rust` and `DEXTOP_AHB_ZEROCOPY=1`: non-Deck client sees v4 + single `zwp_linux_dmabuf_v1` (no dup global); toggle off preserves v3/non-Deck contract (existing assertion at :152).
8. **Device smoke (manual, Redmi Pad Pro 5G / API 36):** `deck_ahb_broker_probe.c` reports `Android AHB deserialization status=0`; gamescope 120 Hz launch; `dumpsys meminfo` native heap flat after 30 min zero-copy soak.

## Risks / device testing needed
- Token file path assumes abstract socket name mirrors a filesystem path (true for current `DEXTOP_SOCKET_NS`); if launcher uses pure abstract sockets, expose token via JNI getter instead of file.
- `getuid()` of compositor must equal launcher/session uid; confirm under PRoot uid mapping — pass uid explicitly from Kotlin if not.
- `AHardwareBuffer_sendHandleToUnixSocket` may still block on a stuck target despite `SO_SNDTIMEO`; if device shows stalls, convert target to `O_NONBLOCK` in the glibc proxy and retry on `EAGAIN` from the state machine.
- Wire v2 breaks old clients; roll out broker and `linux_deck_nativewindow.c` in the same build.
- Toggle defaults off on production until 1000-window soak passes; perf A/B vs v1 copy path on 120 Hz.
