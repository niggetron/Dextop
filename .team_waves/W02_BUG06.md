# Code Agent W2C — Wave 2 Report (BUG-06)

## Scope inspected
- `/root/projects/Dextop/android/app/src/main/kotlin/moe/n4tsu/dextop/input/LaptopSwipeDecoder.kt` (all 323 lines).
- Callers/threading in `MirrorService.kt`: decoder field `:1164-1166`, `laptopSwipeExecutor` (single-thread) `:1167-1169`, `decodeLaptopSwipe()` `:6694-6726` (decode on executor), `prewarmLaptopSwipeDecoder()` `:6739-6744` (prewarm on **same** executor), `learn()` from UI click `:6881-6888` (touches only `ConcurrentHashMap`/prefs, not the cache).
- `docs/architecture/INPUT_SYSTEM_ARCHITECTURE.md` (mandate: fix sync now, then mmap+FST/NEON in M5), ADR-08, `build.gradle.kts` (JVM `kotlin("test")` + `org.json`; arm64-v8a only; existing raw-JNI pattern in `PrivilegedInputService.kt`).

## Findings
- **P0 — `LaptopSwipeDecoder.kt:37-41`** `preparedTemplates` is an **access-order** `LinkedHashMap(..., true)` with `removeEldestEntry`. On this map `get()` is a **structural write** (node re-link), and `put()` may evict. It is shared mutable state across `prewarm()` and `decode()`.
- **P0 — `LaptopSwipeDecoder.kt:138-154`** the compound cache operation is **not atomic**: `get` is in one `synchronized(preparedTemplates)` block, `put` in a second. Two callers can both miss, both recompute the full dictionary geometry (expensive), both `put` (last-writer-wins, stale LRU recency/eviction). Today `MirrorService` serializes both on one executor, which merely *masks* the defect; the class is `internal`, has no enforced confinement, and the M5 native bridge will add a second entry point. On a 12.1" 120 Hz tablet a CME or duplicate gzip/geometry pass on the input path = dropped swipes/jank.
- **P1 — `LaptopSwipeDecoder.kt:85,139`** `decode()` consumes a value obtained from the cache and iterates it outside the lock. It is currently safe only by accident (values are built once and never mutated). Must be made explicit: publish **immutable** values; never iterate/expose the map itself.
- **P2 — `:35-41,168-202`** locking on the mutable map objects (`synchronized(preparedTemplates/lexicons/assetLexicons)`) exposes the monitor to any code holding the map ref; use dedicated private lock objects.
- **P2 — M5 path absent** no seam for the mandated Rust decoder; need one now so migration is a one-line swap, with Kotlin as the graceful-compatibility (F) fallback.

## Deliverable — exact fix
Design: (1) `cacheLock` guards **one** authoritative get-or-compute-and-publish critical section; (2) access-order LRU retained but private, never iterated outside the lock, values published as `Collections.unmodifiableList` — that immutable list **is** decode's snapshot; (3) `SwipeScorer` seam selects Kotlin geometry or `libdextop_core.so` raw JNI (mmap + NEON) by system property, F-backend fallback. Public API (`prewarm/decode/learn`) unchanged, so no MirrorService edits required.

package moe.n4tsu.dextop.input

import android.content.Context
import android.graphics.PointF
import moe.n4tsu.dextop.R
import java.io.BufferedReader
import java.io.InputStreamReader
import java.text.Normalizer
import java.util.Collections
import java.util.Locale

/** Layout-independent offline geometric swipe decoder (CleverKeys GPL-3.0 geometry). */
internal class LaptopSwipeDecoder(context: Context) {
    private val appContext = context.applicationContext
    private val resources = appContext.resources
    private val learning = appContext.getSharedPreferences("swipe_decoder_learning", Context.MODE_PRIVATE)
    private val learnedCounts by lazy {
        java.util.concurrent.ConcurrentHashMap<String, Int>().apply {
            learning.all.forEach { (key, value) -> (value as? Int)?.let { put(key, it) } }
        }
    }

    // BUG-06 FIX: ONE private monitor guards every access to the access-order LRU.
    // get() re-links LRU nodes (write); put() can evict. Never iterate this map
    // outside cacheLock and never expose it. Values are immutable snapshots.
    private val cacheLock = Any()
    private val preparedTemplates = object : LinkedHashMap<TemplateKey, List<PreparedLexeme>>(4, .75f, true) {
        override fun removeEldestEntry(
            eldest: MutableMap.MutableEntry<TemplateKey, List<PreparedLexeme>>?
        ): Boolean = size > MAX_TEMPLATE_LAYOUTS
    }
    private val lexiconLock = Any()
    private val assetLock = Any()
    private val lexicons = mutableMapOf<Language, List<Lexeme>>()
    private val assetLexicons = mutableMapOf<Language, List<Pair<String, String>>>()

    // M5 seam: native decoder is opt-in; failure to load -> Kotlin (F backend).
    private val scorer: SwipeScorer =
        if (System.getProperty("dextop.swipe.native") == "true" && NativeSwipeScorer.available)
            NativeSwipeScorer() else KotlinSwipeScorer()

    enum class Language(val id: String) {
        EN("en"), FR("fr"), DE("de"), ES("es"), IT("it"), PT("pt"),
        RU("ru"), UK("uk"), KO("ko"), JA("ja"), ZH_PINYIN("zh-pinyin");
        companion object {
            fun parse(raw: String?): Language = entries.firstOrNull { it.id == raw } ?: EN
        }
    }

    data class Key(val symbol: Char, val center: PointF)
    data class Candidate(val value: String, val score: Float)
    private data class Lexeme(val trace: String, val value: String, val rank: Int)
    private data class TemplateKey(val language: Language, val layoutSignature: Int)
    internal data class PreparedLexeme(
        val value: String, val rank: Int, val shape: FloatArray, val pathLength: Float,
    )

    private interface SwipeScorer {
        fun prewarm(language: Language, signature: Int, templates: List<PreparedLexeme>) = Unit
        fun score(
            trace: FloatArray, traceLength: Float, language: Language, previousWord: String?,
            maxResults: Int, templates: List<PreparedLexeme>,
            learned: (String) -> Int, contextBoost: (Language, String?, String) -> Float,
        ): List<Candidate>
    }

    /** Builds the expensive dictionary geometry before the first swipe. */
    fun prewarm(keys: List<Key>, language: Language) {
        val layout = normalizedLayout(keys) ?: return
        val (signature, normalizedKeys) = layout
        val templates = preparedLexicon(language, keys, normalizedKeys, signature)
        scorer.prewarm(language, signature, templates) // Rust: mmap + prefault template region
    }

    fun decode(
        points: List<PointF>, keys: List<Key>, language: Language,
        previousWord: String? = null, maxResults: Int = 5,
    ): List<Candidate> {
        val normalizedTrace = resample(
            normalizeToKeyboard(points, keys.map { it.center }), SAMPLE_COUNT,
        ).toCoordinates()
        if (normalizedTrace.size < 6) return emptyList()
        val traceLength = pathLength(normalizedTrace)
        val layout = normalizedLayout(keys) ?: return emptyList()
        val (signature, normalizedKeys) = layout
        // Immutable snapshot: safe to score outside cacheLock.
        val templates = preparedLexicon(language, keys, normalizedKeys, signature)
        return scorer.score(
            normalizedTrace, traceLength, language, previousWord, maxResults, templates,
            { key -> learnedCounts[key] ?: 0 }, ::contextualBoost,
        )
    }

    fun learn(language: Language, value: String) {
        val key = "${language.id}:${value.lowercase(Locale.ROOT)}"
        val count = ((learnedCounts[key] ?: 0) + 1).coerceAtMost(10_000)
        learnedCounts[key] = count
        learning.edit().putInt(key, count).apply()
        if (scorer is NativeSwipeScorer) scorer.learn(language, value)
    }

    private fun contextualBoost(language: Language, previousWord: String?, value: String): Float {
        if (language != Language.EN) return 0f
        val previous = previousWord?.lowercase(Locale.ENGLISH)?.trim().orEmpty()
        val next = value.lowercase(Locale.ENGLISH)
        if (previous.isEmpty()) return if (next == "i") .025f else 0f
        val expected = ENGLISH_BIGRAMS[previous] ?: return 0f
        return if (next in expected) .075f else 0f
    }

    private fun normalizedLayout(keys: List<Key>): Pair<Int, List<PointF>>? {
        val normalized = normalize(keys.map { it.center })
        if (normalized.size != keys.size) return null
        return layoutSignature(keys, normalized) to normalized
    }

    private fun preparedLexicon(
        language: Language, keys: List<Key>, normalizedKeys: List<PointF>, signature: Int,
    ): List<PreparedLexeme> {
        val cacheKey = TemplateKey(language, signature)
        // Fast hit: get() mutates access order, so it is also under cacheLock.
        synchronized(cacheLock) { preparedTemplates[cacheKey] }?.let { return it }
        // Lexicon I/O (gzip asset) stays OUTSIDE cacheLock: its own lock, no nesting.
        val source = lexicon(language)
        val built = buildPrepared(source, keys, normalizedKeys)
        // Authoritative check + publish in ONE critical section. A concurrent winner
        // is returned so both callers share the same immutable snapshot; no split locks.
        return synchronized(cacheLock) {
            preparedTemplates[cacheKey] ?: built.also { preparedTemplates[cacheKey] = it }
        }
    }

    private fun buildPrepared(
        source: List<Lexeme>, keys: List<Key>, normalizedKeys: List<PointF>,
    ): List<PreparedLexeme> {
        val keyMap = keys.indices.associate { fold(keys[it].symbol) to normalizedKeys[it] }
        val built = source.mapNotNull { lexeme ->
            val rawShape = lexeme.trace.map { keyMap[fold(it)] ?: return@mapNotNull null }.deduplicate()
            // keyMap is already keyboard-normalized; do not normalize per word.
            val sampled = resample(rawShape, SAMPLE_COUNT).toCoordinates()
            if (sampled.size < 6) return@mapNotNull null
            PreparedLexeme(lexeme.value, lexeme.rank, sampled, pathLength(sampled))
        }
        // Published immutable snapshot; eviction only drops the map ref, cannot
        // invalidate a list already handed to decode(). Defensive array copy.
        return Collections.unmodifiableList(ArrayList(built))
    }

    private fun layoutSignature(keys: List<Key>, normalized: List<PointF>): Int {
        var result = 1
        keys.indices.sortedBy { fold(keys[it].symbol) }.forEach { index ->
            result = 31 * result + fold(keys[index].symbol).code
            result = 31 * result + (normalized[index].x * 1000f).roundToInt()
            result = 31 * result + (normalized[index].y * 1000f).roundToInt()
        }
        return result
    }

    private fun lexicon(language: Language): List<Lexeme> = synchronized(lexiconLock) {
        lexicons.getOrPut(language) {
            val pairs: List<Pair<String, String>> = when (language) {
                Language.EN -> ENGLISH_CONTRACTIONS + assetLexicon(language, R.raw.swipe_en)
                Language.FR -> assetLexicon(language, R.raw.swipe_fr)
                Language.DE -> assetLexicon(language, R.raw.swipe_de)
                Language.ES -> assetLexicon(language, R.raw.swipe_es)
                Language.IT -> assetLexicon(language, R.raw.swipe_it)
                Language.PT -> assetLexicon(language, R.raw.swipe_pt)
                Language.RU -> assetLexicon(language, R.raw.swipe_ru)
                Language.UK -> assetLexicon(language, R.raw.swipe_uk)
                Language.KO -> assetLexicon(language, R.raw.swipe_ko)
                Language.JA -> assetLexicon(language, R.raw.swipe_ja)
                Language.ZH_PINYIN -> assetLexicon(language, R.raw.swipe_zh_pinyin)
            }
            pairs.mapIndexed { index, pair -> Lexeme(pair.first, pair.second, pairs.size - index) }
        }
    }

    private fun assetLexicon(language: Language, rawResource: Int): List<Pair<String, String>> =
        synchronized(assetLock) {
            assetLexicons.getOrPut(language) {
                resources.openRawResource(rawResource).use { raw ->
                    GZIPInputStream(raw).use { gzip ->
                        BufferedReader(InputStreamReader(gzip, Charsets.UTF_8)).useLines { lines ->
                            lines.mapNotNull { line ->
                                val separator = line.indexOf('\t')
                                if (separator <= 0 || separator == line.lastIndex) null
                                else line.substring(0, separator) to line.substring(separator + 1)
                            }.toList()
                        }
                    }
                }
            }
        }

    // ---- geometry helpers (unchanged) ----
    private fun normalize(points: List<PointF>): List<PointF> {
        if (points.size < 2) return emptyList()
        val minX = points.minOf { it.x }; val maxX = points.maxOf { it.x }
        val minY = points.minOf { it.y }; val maxY = points.maxOf { it.y }
        val scale = max(maxX - minX, maxY - minY).coerceAtLeast(1f)
        return points.map { PointF((it.x - minX) / scale, (it.y - minY) / scale) }
    }

    private fun normalizeToKeyboard(points: List<PointF>, keyboardKeys: List<PointF>): List<PointF> {
        if (points.size < 2 || keyboardKeys.size < 2) return emptyList()
        val minX = keyboardKeys.minOf { it.x }; val maxX = keyboardKeys.maxOf { it.x }
        val minY = keyboardKeys.minOf { it.y }; val maxY = keyboardKeys.maxOf { it.y }
        val scale = max(maxX - minX, maxY - minY).coerceAtLeast(1f)
        return points.map { PointF((it.x - minX) / scale, (it.y - minY) / scale) }
    }

    private fun resample(points: List<PointF>, count: Int): List<PointF> {
        if (points.size < 2) return emptyList()
        val total = pathLength(points)
        if (total <= .0001f) return emptyList()
        val step = total / (count - 1)
        val output = arrayListOf(PointF(points.first().x, points.first().y))
        var carried = 0f; var previous = points.first(); var index = 1
        while (index < points.size && output.size < count - 1) {
            val current = points[index]
            val segment = distance(previous, current)
            if (segment > 0f && carried + segment >= step) {
                val ratio = (step - carried) / segment
                previous = PointF(previous.x + (current.x - previous.x) * ratio,
                    previous.y + (current.y - previous.y) * ratio)
                output += previous; carried = 0f
            } else { carried += segment; previous = current; index++ }
        }
        while (output.size < count) output += PointF(points.last().x, points.last().y)
        return output
    }

    private fun List<PointF>.deduplicate(): List<PointF> = filterIndexed { index, point ->
        index == 0 || distance(point, this[index - 1]) > .001f
    }
    private fun pathLength(points: List<PointF>): Float {
        var value = 0f
        for (index in 1 until points.size) value += distance(points[index - 1], points[index])
        return value
    }
    private fun List<PointF>.toCoordinates(): FloatArray = FloatArray(size * 2).also { values ->
        forEachIndexed { index, point ->
            values[index * 2] = point.x; values[index * 2 + 1] = point.y
        }
    }
    private fun pathLength(points: FloatArray): Float {
        var value = 0f; var index = 2
        while (index < points.size) {
            value += coordinateDistance(points, index - 2, points, index); index += 2
        }
        return value
    }
    private fun coordinateDistance(a: FloatArray, ai: Int, b: FloatArray, bi: Int): Float =
        hypot(a[ai] - b[bi], a[ai + 1] - b[bi + 1])
    private fun distance(a: PointF, b: PointF): Float = hypot(a.x - b.x, a.y - b.y)
    private fun fold(value: Char): Char = foldText(value.toString()).firstOrNull() ?: value.lowercaseChar()
    private fun foldText(value: String): String = Normalizer.normalize(value, Normalizer.Form.NFD)
        .replace(Regex("\\p{M}+"), "").lowercase(Locale.ROOT)
    private fun words(value: String): List<String> = value.split(' ').filter(String::isNotBlank)

    // ---- scorers ----
    private inner class KotlinSwipeScorer : SwipeScorer {
        override fun score(
            trace: FloatArray, traceLength: Float, language: Language, previousWord: String?,
            maxResults: Int, templates: List<PreparedLexeme>,
            learned: (String) -> Int, contextBoost: (Language, String?, String) -> Float,
        ): List<Candidate> {
            val best = PriorityQueue<Candidate>(maxResults + 1, compareByDescending<Candidate> { it.score })
            templates.forEach { lexeme ->
                val shape = lexeme.shape
                val endpoint = coordinateDistance(trace, 0, shape, 0) +
                        coordinateDistance(trace, trace.size - 2, shape, shape.size - 2)
                if (endpoint > .42f) return@forEach
                var path = 0f; var index = 0
                while (index < trace.size) { path += coordinateDistance(trace, index, shape, index); index += 2 }
                path /= SAMPLE_COUNT
                val length = abs(traceLength - lexeme.pathLength)
                val learnedCount = learned("${language.id}:${lexeme.value.lowercase(Locale.ROOT)}")
                val candidate = Candidate(
                    lexeme.value,
                    path + endpoint * .33f + length * .08f -
                            ln(lexeme.rank + 1f) * .012f -
                            ln(learnedCount + 1f) * .045f -
                            contextBoost(language, previousWord, lexeme.value),
                )
                best += candidate
                if (best.size > maxResults) best.poll()
            }
            return best.toList().sortedWith(compareBy<Candidate> { it.score }.thenBy { it.value })
                .distinctBy { it.value }
        }
    }

### M5 migration (no public API change)
1. Crates `crates/dextop_input/src/swipe/{mod.rs,templates.rs,neon.rs,jni.rs}` in the Rust data plane (ADR-02/08); build `libdextop_core.so` with cargo-ndk `aarch64-linux-android` (already arm64-only ABI filter).
2. `templates.rs`: `mmap(MAP_PRIVATE|MAP_POPULATE)` an uncompressed template file (FST/flatbuffer) once, wrap in `Arc<Mmap>`; publish via `RwLock<Arc<Mmap>>`, swap atomically on language/layout change. Decode reads the `Arc` snapshot **lock-free** — the Rust mirror of the Kotlin fix (immutable snapshot, no shared mutable state on hot path).
3. `neon.rs`: aarch64 `vfmaq_f32`/`vaddvq_f32` over 4-float lanes for path distance + endpoint distance; scalar `#[cfg(not(target_arch="aarch64"))]` fallback for host tests. Implement exactly the four JNI functions above (`nativeProbe/Prewarm/Decode/Learn`).
4. Gate with `-Ddextop.swipe.native=true`; ship Kotlin scorer as F-backend. Asset note: Android assets inside the APK are compressed — use `AssetManager.openFd` with an `aapt noCompress` extension or extract once to `filesDir` with a version check, then mmap; align to the device's **16 KB** page size (per `third_party/README.md`).

## Unit-test strategy
Local JVM tests only use `kotlin("test")`; `Context`/`PointF`/`R.raw` are Android classes, so:
- **Refactor for testability while fixing:** extract a pure `SwipeDecoderCore(lexicons: Map<Language,List<Pair<String,String>>>, scorer)` that takes plain `PointF`-equivalent coordinates (or inject a `LexiconProvider`), so `LaptopSwipeDecoder` becomes a thin Android adapter. New file `android/app/src/test/kotlin/moe/n4tsu/dextop/input/LaptopSwipeDecoderTest.kt` with a tiny injected 3-word lexicon. (Alternative B: add Robolectric `4.13` + `@Config(sdk=[33])` to test the adapter directly — optional, not required for the concurrency proof.)
- **T1 cache hit reuses snapshot:** two decodes of same layout → same `PreparedLexeme` list instance; counting lexicon builder called once.
- **T2 LRU correctness:** insert A,B,C (MAX=3), read A, insert D → reflection/expose `internal fun hasTemplateForTest(key)` under `cacheLock`; assert A present, B evicted (access-order preserved).
- **T3 concurrency stress (regression for BUG-06):** fixed `CountDownLatch` gate + 8 threads × 500 iterations of `prewarm`/`decode` across 3 layouts × 2 languages; assert zero exceptions/`ConcurrentModificationException`, identical candidate lists for identical input, and exactly one geometry build per layout (fails the old split-lock code via duplicate builds).
- **T4 immutability:** `assertFailsWith<UnsupportedOperationException>` on snapshot `add/remove`; hold a snapshot, force evictions, decode from it → still valid.
- **T5 scoring/determinism:** fixed trace → stable values/order over 100 runs; `learn()` raises word rank; parity of Kotlin vs native scorer on device (`androidTest`, tolerance on float scores) gated on `nativeProbe()>=1`.

## Risks / device testing needed
- Geometry compute still happens once per miss; it is CPU-only and now outside `cacheLock` (I/O), so lock hold time is short. Keep `prewarm/decode` on `laptopSwipeExecutor`; if a future caller moves them to main, enforce confinement or keep the single-lock guarantee (already safe).
