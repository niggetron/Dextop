## Findings

**P0 — `DesktopModeConfigurator.kt:105–122` (BUG-02 root cause).** Two `Handler(Looper.getMainLooper()).postDelayed` runnables each perform 1–2 blocking `privilegedAccess.execute("wm", …)` binder calls on the UI thread at 250 ms and 750 ms. On API 36 / HyperOS 3 these `wm set-display-*` calls can take tens of ms (WMShell + SurfaceFlinger round trip), producing jank/ANR on a 120 Hz tablet precisely while the new virtual display is being published. Neither runnable is cancellable: after `restore()`/`stop()` a stale re-apply can overwrite a freshly restored windowing mode on the next session. **Fix:** replace both runnables with two child coroutines on a session-scoped `CoroutineScope(SupervisorJob() + Dispatchers.IO)` using cancellable `delay`, wrapped in `coroutineScope { … }` for structured concurrency; cancel the scope in teardown.

**P0 — `DesktopModeConfigurator.kt:46–124` (synchronous part).** The immediate `cmd settings put global`, `wm set-display-engagement-mode`, and windowing-strategy loop also call blocking `execute()` on the caller. All MirrorService callers are main-looper paths (12185 `configureBeforePublish`, 12270 `configureBeforePublish`, 12708 via `configureDisplay()` from 12283/12489/13395). **Fix:** move the entire method body onto the IO scope; the return value is ignored by every caller, so changing it to `Job?` is source-compatible at the call sites.

**P0 — `DesktopModeConfigurator.kt:19–22, 49–63` (state races once async).** `savedGlobals`, `forcedFreeformGlobalsApplied`, `applied` were mutated only on main; after the move, the forced-freeform bookkeeping runs on IO. **Fix:** `Collections.synchronizedList`, `@Volatile` flags, and a `synchronized(freeformGate)` compare-and-set for the one-shot global write.

**P1 — `MirrorService.kt:13997–14006`.** `finishStop()` deliberately skips `desktopModeConfigurator.restore()` when an Auto/cover session is active, so relying on `restore()` alone leaves pending re-applies alive across the phone-session teardown. **Fix:** add an explicit `cancelPendingWork()` at the top of `stop()` (13864–13866) and in `onDestroy()` (2830–2832). `cancelPendingWork()` is synchronous (`Job.cancel()` only), preserving the `onTaskRemoved` comment at 2885–2888 that restoration must happen before the process dies.

**P1 — `MirrorService.kt:13692–13721`.** `routeNotificationTask` uses the same anti-pattern (`root?.postDelayed` + two blocking `execute` calls on main). Out of BUG-02 scope but the same StrictMode/jank class; file as a follow-up, do not regress it.

**P2 — `MirrorService.kt:3065, 7960, 8184, 12834, 13814`.** Additional `execute()` calls reachable from main (Plasma `privilegedCommand`, diagnostics, `launchHome`, `setPhoneNavigationDisabled`). Not touched here; note for the MirrorService decomposition (BUG-03).

**P2 — `DesktopModeConfigurator.kt:31–42`.** `applyForCurrentDevice()` still performs `Settings.Global.getString/putString` (binder + `commit()` in `rememberGlobal`) on main. Making it async would race the display-create ordering at 12128/12168/12228, so leave it in M0 and track separately.

```kotlin
package moe.n4tsu.dextop

import android.content.ContentResolver
import android.content.Context
import android.os.Build
import android.provider.Settings
import java.util.Collections
import java.util.concurrent.ConcurrentHashMap
import kotlin.coroutines.coroutineContext
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.Job
import kotlinx.coroutines.SupervisorJob
import kotlinx.coroutines.cancel
import kotlinx.coroutines.coroutineScope
import kotlinx.coroutines.delay
import kotlinx.coroutines.ensureActive
import kotlinx.coroutines.launch

internal data class StrategyAttempt(val strategy: String, val succeeded: Boolean, val detail: String)

internal class DesktopModeConfigurator(
    private val context: Context,
    private val resolver: ContentResolver,
    private val privilegedAccess: PrivilegedAccess,
    private val environment: DesktopEnvironment,
    private val sessionJournal: SessionJournal,
    // Test seams only: production keeps the original five-argument call form.
    private val ioDispatcher: CoroutineDispatcher = Dispatchers.IO,
    private val commandRunner: (Array<out String>) -> PrivilegedAccess.CommandResult =
        { args -> privilegedAccess.execute(*args) }
) {
    private data class SavedGlobal(val key: String, val value: String?)

    private val savedGlobals = Collections.synchronizedList(mutableListOf<SavedGlobal>())
    @Volatile private var applied = false
    @Volatile private var forcedFreeformGlobalsApplied = false

    // One IO scope per desktop session. cancelPendingWork()/restore() replace it
    // instead of reusing it, so work scheduled after teardown never lands on a
    // cancelled scope and a later session starts clean.
    private val scopeLock = Any()
    private val freeformGate = Any()
    @Volatile private var sessionScope: CoroutineScope = newSessionScope()
    private val displayJobs = ConcurrentHashMap<Int, Job>()

    private fun newSessionScope(): CoroutineScope = CoroutineScope(SupervisorJob() + ioDispatcher)

    fun applyForCurrentDevice(): List<StrategyAttempt> {
        if (applied) return emptyList()
        applied = true
        if (environment.platformManaged) {
            OperationLog.i(context, "DesktopMode", "platform-managed environment=${environment.id}")
            return listOf(StrategyAttempt("platform_managed", true, environment.id))
        }
        return environment.temporaryGlobalSettings.map { (key, value) ->
            runCatching {
                val previous = Settings.Global.getString(resolver, key)
                savedGlobals += SavedGlobal(key, previous)
                sessionJournal.rememberGlobal(key, previous)
                check(Settings.Global.putString(resolver, key, value)) { moe.n4tsu.dextop.localText("uiSettingRejected") }
                StrategyAttempt("global:$key", true, "$previous -> ${value ?: "<deleted>"}")
            }.getOrElse {
                OperationLog.w(context, "DesktopMode", "optional global setting failed key=$key", it)
                StrategyAttempt("global:$key", false, it.message.orEmpty())
            }
        }
    }

    /**
     * Optional configuration: failure is isolated to this display and never aborts startup.
     * All blocking `wm`/`cmd` IPC runs on the session IO scope, never on the caller
     * (the main looper in MirrorService). The returned Job is the cancellation unit;
     * all current callers ignore it.
     */
    fun configureDisplay(displayId: Int, forceFreeform: Boolean = false): Job? {
        if (!environment.configureFreeformWindowing && !forceFreeform) return null
        // A newer request for the same display supersedes an older pending re-apply.
        displayJobs[displayId]?.cancel()
        val scope = synchronized(scopeLock) { sessionScope }
        val job = scope.launch {
            val attempts = configureDisplayNow(displayId, forceFreeform)
            if (attempts.any { it.strategy != "display_engagement" && it.succeeded }) {
                // Structured concurrency: both re-applies are children of this job.
                // Original 250/750 ms timing is kept; cancellation propagates to both.
                coroutineScope {
                    launch { reapplyWindowing(displayId, 250L) }
                    launch { reapplyWindowing(displayId, 750L) }
                }
            }
        }
        displayJobs[displayId] = job
        job.invokeOnCompletion { displayJobs.remove(displayId, job) }
        return job
    }

    private suspend fun configureDisplayNow(displayId: Int, forceFreeform: Boolean): List<StrategyAttempt> {
        val attempts = mutableListOf<StrategyAttempt>()
        if (forceFreeform && claimForcedFreeformGlobals()) {
            listOf("enable_freeform_support", "force_resizable_activities").forEach { key ->
                coroutineContext.ensureActive()
                val previous = Settings.Global.getString(resolver, key)
                savedGlobals += SavedGlobal(key, previous)
                sessionJournal.rememberGlobal(key, previous)
                val result = commandRunner(arrayOf("cmd", "settings", "put", "global", key, "1"))
                attempts += StrategyAttempt("global:$key", result.succeeded, result.error.ifBlank { result.output })
            }
        }
        if (Build.VERSION.SDK_INT >= 35) {
            coroutineContext.ensureActive()
            val engagement = commandRunner(
                arrayOf("wm", "set-display-engagement-mode", "-d", displayId.toString(), "3")
            )
            attempts += StrategyAttempt(
                "display_engagement",
                engagement.succeeded,
                engagement.error.ifBlank { engagement.output }
            )
        }
        val windowingStrategies = if (forceFreeform) {
            // Electron DEX order: cmd window before the older activity_task command.
            listOf("cmd_window", "wm")
        } else environment.windowingStrategies
        for (strategy in windowingStrategies) {
            coroutineContext.ensureActive()
            val args = when (strategy) {
                "cmd_window" -> arrayOf(
                    "cmd", "window", "set-display-windowing-mode", "-d", displayId.toString(), "5"
                )
                "wm" -> arrayOf("wm", "set-display-windowing-mode", "-d", displayId.toString(), "5")
                "activity_task_manager" -> arrayOf(
                    "cmd", "activity_task", "set-display-windowing-mode", displayId.toString(), "5"
                )
                else -> continue
            }
            val result = commandRunner(args)
            val attempt = StrategyAttempt(strategy, result.succeeded, result.error.ifBlank { result.output })
            attempts += attempt
            OperationLog.i(
                context, "DesktopMode",
                "windowing display=$displayId strategy=$strategy success=${attempt.succeeded} detail=${attempt.detail}"
            )
            if (result.succeeded) break
        }
        return attempts
    }

    private suspend fun reapplyWindowing(displayId: Int, delayMs: Long) {
        delay(delayMs)
        coroutineContext.ensureActive()
        if (Build.VERSION.SDK_INT >= 35) {
            commandRunner(arrayOf("wm", "set-display-engagement-mode", "-d", displayId.toString(), "3"))
        }
        coroutineContext.ensureActive()
        val result = commandRunner(
            arrayOf("wm", "set-display-windowing-mode", "-d", displayId.toString(), "5")
        )
        OperationLog.i(
            context,
            "DesktopMode",
            "windowing reapply display=$displayId delay=$delayMs success=${result.succeeded} " +
                "detail=${result.error.ifBlank { result.output }}"
        )
    }

    private fun claimForcedFreeformGlobals(): Boolean = synchronized(freeformGate) {
        if (forcedFreeformGlobalsApplied) false else {
            forcedFreeformGlobalsApplied = true
            true
        }
    }

    /** Cancels in-flight and delayed work without restoring settings; synchronous, main-safe. */
    fun cancelPendingWork() {
        val oldScope = synchronized(scopeLock) {
            val previous = sessionScope
            sessionScope = newSessionScope()
            previous
        }
        oldScope.cancel()
        displayJobs.clear()
    }

    fun restore() {
        cancelPendingWork()
        sessionJournal.restoreSystemSettings()
        OperationLog.i(context, "DesktopMode", "restored settings count=${savedGlobals.size}")
        savedGlobals.clear()
        applied = false
        forcedFreeformGlobalsApplied = false
    }
}
```

Design notes:
- `SupervisorJob()` — a failed/cancelled re-apply child never kills the session scope or its sibling.
- `coroutineScope { launch…; launch… }` — true structured concurrency: the outer `Job` completes only after both children, and cancelling it cancels both. No orphan runnables.
- `ensureActive()` before every binder call gives prompt cancellation between commands (the blocking `execute()` itself cannot be interrupted without changing `PrivilegedAccess`).
- `invokeOnCompletion` removes the map entry, so no `Job` reference leak across sessions.
- `cancelPendingWork()` only calls `cancel()` + map clear — it does not await IO, so `onTaskRemoved` (2885–2888) keeps its synchronous guarantee.

## Risks / device testing needed

- **Async ordering vs. "before publish"**: `configureBeforePublish` (12181–12188, 12268–12272) previously ran synchronously before the VirtualDisplay was published. New work starts a few milliseconds later on IO. Verify on Xiaomi Redmi Pad Pro 5G / HyperOS 3 (API 36) and on a Pixel that the first freeform mode still lands before WMShell's initial task creation — the retained 250/750 ms re-applies are the designed safety net. If a device shows a transient portrait/phone-sized first frame, consider having `VirtualDisplayPlatform.openOwned` await the returned `Job` off-main rather than reintroducing main-thread blocking.
- **Suppress semantics**: per-display `cancel()` means a rapid reconfigure replaces earlier pending re-applies. Confirm no device needs the old duplicate re-applies (they were redundant, not additive).
- **Restore race**: `restore()` cancels jobs but cannot interrupt a `wm` call already in flight; the command may finish after `restoreSystemSettings()`. Test lock-screen suspend/resume (11328 → 12489) and "temporarily return to Android" (8346–8367) repeatedly for a settings flip-back.
- **`onTaskRemoved`** (2864–2892): confirm `cancelPendingWork()` alone is cheap enough to stay within the vendor launcher's kill window.
- **Cancellation blind spot**: `PrivilegedAccess.execute()` blocking binder call is not interruptible; only inter-command checks are cancellable. If device traces show long `waitFor()` stalls, a follow-up should add an interruptible overload in `PrivilegedAccess` (out of BUG-02 scope).
- Verify no behavior regression in the `display_engagement` gate: `SDK_INT >= 35` branch and the exact `"3"` / `"5"` mode values must be unchanged on the tablet and on any API 33/34 compat device.
